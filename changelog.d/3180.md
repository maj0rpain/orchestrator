The repo's test suite gets a suite budget: `scripts/test/suite-budget` holds the most CPU seconds the durations file's CPU column may sum to, first set at 1160 from a full refresh's 1051.8 plus a tenth. The durations file becomes a ledger whose section and suite lines carry a fingerprint of the test text they were measured from. `section-durations.sh --stale` records only the stale and missing lines, scaled to the last full refresh's machine through five calibration sections. `docs_lint.sh` fails a stale ledger, a change whose total is over the budget and above its base's, and a budget edit beside any file but the durations file; its `--fragment-only` mode, which CI's fragment job runs, now enforces the last two. A changed durations or budget file selects only the always-run checks in `affected.sh`, which hands its base to `docs_lint.sh` as `DOCS_LINT_BASE`. CONTRIBUTING, CLAUDE.md and the glossary say what a session does at the budget.
