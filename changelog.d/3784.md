Section durations are now recorded in per-branch durations fragments, so two open changes that only record durations no longer conflict. `section-durations.sh --stale` writes only the current branch's fragment, `scripts/test/durations.d/<branch>.tsv` (each `/` as `-`), refuses on a detached HEAD, and never edits the durations file or another fragment. Every reader - `orch_test.sh`'s start order and CI shard dealing, `docs_lint.sh`'s ledger freshness and budget total rules (the base total read from the merge-base tree's effective record), and `--stale` itself - reads the effective record: the durations file overlaid by every fragment. A new `--fold` mode writes the effective record into the durations file and deletes the fragments, measuring nothing; the version-bump Action runs it on every push to main, committing "Fold section durations" when there is no version bump. A full refresh still writes the durations file and deletes every fragment. `affected.sh` treats a changed fragment as it treats a changed durations file, and rule 3 allows fragment deletions beside a budget edit. ADR-0067 records the choice, and CLAUDE.md and CONTRIBUTING say a session commits its durations fragment.
