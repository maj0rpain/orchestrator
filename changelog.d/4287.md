bump: patch

`orch.sh branch` now runs as a Python converted noun, from
`scripts/orch_py/orch/branch.py`: `create`, `off`, `busy`, `base-sha`, `sync`
and `retire`. Their usage lines, messages and exit codes are unchanged, except
that a `branch create` restart beside a tag of the same name no longer prints
git's "refname is ambiguous" warning on success. `retire` now prints git's own
error ahead of its `orch:` line when git refuses the retirement record, as the
bash did. The bash `branch` module and its test section are deleted, along
with the bash helpers the conversion left with no caller, and the test cases
that only ran Python nouns move to pytest.
