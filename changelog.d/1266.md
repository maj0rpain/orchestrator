bump: patch

spec-review's validation helpers no longer take a collect mode argument that
makes them react two ways: `check` and `apply` share one validation pass, which
always visits every anchor, declined ones included, so `apply` now refuses a
batch whose declined anchor is broken, as `check` already did. The anchor helper
is renamed for what it does and counts the anchors it visits, so `check`'s
summary no longer re-walks the items to count them. `common.sh`'s
`labels_have` becomes the general `list_has`, used at every newline-list
membership test, including the hand-rolled ones in spec-review.sh and
ticket.sh (#1266).
