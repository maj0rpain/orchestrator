Relabelling an autopilot issue one phase back (`orch:review` to `orch:implement`, `orch:implement` to `orch:spec`) now drives `redo`: in an autopilot session `redo review` and `redo spec` retire each handoff comment they would move into a `pre-redo-*` folder, before moving any state, so a redo that dies partway is finished by the next. `autopilot watch [--every <seconds>]` repeats `tick` (default 60 s), refuses a second live instance of the clone through a pidfile under the git common directory, replaces a dead one, reports a failed tick on stderr and carries on, and removes its pidfile when interrupted.
