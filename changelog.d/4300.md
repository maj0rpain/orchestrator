bump: patch

`orch.sh base`, `state`, `repo` and `default-branch` now run as Python
converted nouns: `base` and `default-branch` from
`scripts/orch_py/orch/base.py`, `state` from `scripts/orch_py/orch/state.py`
and `repo` from `scripts/orch_py/orch/repo.py`. Their usage lines, messages and
exit codes are unchanged, except that `state get <key>` and `state set` on an
unreadable `state.json` now die with the unreadable-state message. That was the
last bash noun, so `orch.sh` shrinks to the entry point that runs the Python
package. Without `python3`, an unknown noun and a run outside a git repository
now get the `python3` refusal, where they died as an unknown command or outside
a repository before. The bash modules the conversions left without a caller,
the module loader and their test sections are deleted. The docs lint's CLI
conventions check now reads the routed nouns from `cli.py`.
