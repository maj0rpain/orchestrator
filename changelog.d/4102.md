`orch.sh init`, `slug`, `status`, `archive` and `help` (with `-h`, `--help`
and a bare `orch.sh`) now run as Python converted nouns, from
`scripts/orch_py/orch/`. Their arguments, output, exit codes and `orch:`
messages are unchanged, and the `state.json` that `init` writes is byte for
byte what bash `init` wrote. Without python3 all five now die pointing at
`orch.sh doctor`, as every converted noun does. New Python concept modules
carry the planning allowlist (pinned to the bash module by a parity test), the
checkout scan and busy refusal, the branch keys and the side-checkout archive.
The bash `init` and `global` modules and their bash tests are removed, along
with the helpers that had no other caller; `orch.sh`'s own entry-point checks
moved to the loader's tests. A converted noun now also runs from a plugin path
containing a colon: the Python bootstrap puts the package on `sys.path` rather
than `PYTHONPATH`. Closes #4012 and #4073, whose `init` git-exclude section no
longer exists.
